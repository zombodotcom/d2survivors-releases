# D2 Survivors builds

Release zips of D2 Survivors, a survivors-like built on Diablo II: Resurrected's art. No source code here.

You need your own Diablo II: Resurrected install (Battle.net or Steam); the game reads its art from there and ships no Blizzard files. Download the latest zip from Releases, unzip it, run `D2SurvivorsLauncher.exe`. `README.txt` in the zip explains the rest. The launcher updates itself from here.

Fan project, not affiliated with or endorsed by Blizzard Entertainment.
