# D2 Survivors builds

Release zips of D2 Survivors, a game built on Diablo II: Resurrected's art. No source code here.

It has two modes:

- **Survivors**: a run from Act I to Baal against the horde, with skills that cast themselves and level-up cards.
- **Campaign**: a faster Diablo II with saved characters. Towns with D2's people, waypoints, Normal, Nightmare and Hell, softcore and hardcore, real D2 items, runewords, the skill tree, vendors, quests, caves, act bosses in their lairs, charms and the Cow Level.

You need your own Diablo II: Resurrected install (Battle.net or Steam); the game reads its art from there and ships no Blizzard files. Download the latest zip from Releases, unzip it, run `D2SurvivorsLauncher.exe`. The launcher updates itself from here. In the game, H opens the Guide with the controls.
