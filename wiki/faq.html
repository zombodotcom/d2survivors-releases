FAQ and troubleshooting

Most problems are the game not finding D2R, or the graphics card. The files below tell what went wrong.

What do I need?

  • Windows 10 or 11.
  • Diablo II: Resurrected installed, from Battle.net or Steam. The game draws its art and sound from your install.
  • A graphics card with 4 GB of video memory or more.

Does it start D2R or Battle.net?

No. It only reads D2R's files from its folder. It never starts D2R, its launcher or Battle.net, and it ships no Blizzard files.

The launcher says D2R isn't found

Press Auto-detect, or Browse... to D2R's folder: the one with D2R's .build.info file, or on Steam its Data folder with .build.config inside. For example:

  • C:\Program Files (x86)\Diablo II Resurrected (Battle.net)
  • C:\Program Files (x86)\Steam\steamapps\common\Diablo II Resurrected (Steam)

Unzip D2 Survivors anywhere except inside D2R's folder.

Steam edition, and check_d2r.bat

The Steam edition works too. It stores its files differently (no .build.info; a Data folder of numbered .data files), and the game reads both.

If the launcher or the game says D2R isn't found, or the game can't load D2R's files, run check_d2r.bat. Drag D2R's folder onto it if D2R is somewhere unusual. It only reads D2R's files, says whether they load, and saves what it found in d2r_check.txt. Send that file back.

Windows warns about an unknown app

The first time, Windows may say it protected your PC. Click More info, then Run anyway. The game isn't signed, so Windows doesn't know it yet.

Updating

The launcher checks for a new build each time it starts, and shows its own build in the top right corner. When there is one, a bar says Update available: press Update, and it downloads the build, swaps its files and restarts. Close the game first.

Or download the new zip and unzip it over the folder. Either way your settings, progress, logs and spell review marks are kept.

It runs slowly: perf.log

Turn on Show performance in the options, or press F3 in a run. The game then writes perf.log beside the exe: frame times and video memory, a line each second. Try lower settings in the launcher, and send perf.log with log.txt if it stays slow.

Video memory

The game needs a graphics card with 4 GB or more; at the top settings it uses about 2 GB. If the card runs short, lower the settings in the launcher. perf.log shows how much video memory is in use.

The game crashed

It writes what went wrong to crash.txt beside the exe. Run play.bat to see the console as well. Send log.txt, perf.log and crash.txt.

Files beside the exe

settings.tomlYour settings
progress.tomlShards, talents, Armory, acts reached
log.txtThe game's log
perf.logFrame times and video memory (with Show performance on)
spell_review.txtSpell review marks
crash.txtWhat went wrong, if the game crashed
d2r_check.txtWhat check_d2r.bat found
